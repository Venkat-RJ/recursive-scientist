# Scientific Research Authoring

- Read the project's main.md and relevant linked evidence first. Recover the question, evaluation contract, competing hypotheses, and unresolved issues before proposing work.
- Before execution, record a stable hypothesis ID, prediction, falsification criterion, comparator, inputs, and run budget. State what would distinguish competing explanations.
- Record every attempt under a stable experiment ID. Link its code snapshot or Git revision, actual evaluator output or other source evidence, and observations. Report validity, split, and limitations. Preserve failures, interruptions, inconclusive attempts, and contradictions.
- Keep observations separate from interpretation. Update Current Understanding only as far as the evidence supports. Revise the Investigation Plan and Next Investigation and explain material changes.
- Keep the notebook concise. Store detailed logs and outputs in linked project files so a fresh conversation can continue from the notebook without chat history.
- Use the project's existing tools and respect the user's scope. Keep synthetic, training, and held-out evidence separate.
