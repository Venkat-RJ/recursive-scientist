# Data Sources

## Synthetic demo

`data/demo.csv` and `data/demo-2.csv` are original deterministic fixtures generated by `scripts/generate_demo.py` with seeds 42 and 73. They use the same four CSV columns as the published instances. Demo results are synthetic evidence only.

## Published instances

Ana Sofia M. Martins, Jorge M. S. Valente, and Jeffrey E. Schaller (2026). *A Computational Evaluation of New and Existing Dispatching Rules for the Single Machine Total Weighted Tardiness Problem*. International Transactions in Operational Research 33, 3882–3904. [DOI](https://doi.org/10.1111/itor.70146)

The [authors’ dataset repository](https://github.com/jorge-valente/single-machine-total-weighted-tardiness-instances) provides separate training and test ZIPs. The importer pins revision `d5d42e4f55896354dc2ba2d400d058de8857e916` and checks the exact archive size and SHA-256. It prints the source URL and hash. Each published evaluation records both alongside a hash of the selected instance files.

```sh
python3 scripts/fetch_benchmark.py --split train
python3 evaluator.py --split train
```

The evaluator reads all 250 published 50-job training instances directly from the verified ZIP. It preserves the original job IDs and accepts negative due dates, which the published generator can produce.

Once the candidate is chosen, run the held-out evaluation separately. It uses all 2,500 50-job test instances and chooses the comparator using the training archive. Keep that archive in place.

```sh
python3 scripts/fetch_benchmark.py --split test
python3 evaluator.py --split test
```

To import an existing copy offline, pass `--archive /path/to/training_set.zip` or the equivalent test archive. The default candidate timeout is 30 seconds for the whole split. Change it with `--timeout SECONDS` if the experimental protocol calls for a different budget.
